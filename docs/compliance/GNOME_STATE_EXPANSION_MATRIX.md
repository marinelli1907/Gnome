# Gnome State Expansion Matrix

Checked: 2026-08-24
Status: Expansion governance document. Ohio is the only first-priority jurisdiction in this launch directive.

## State Coverage Definitions

| Status | Meaning | Product behavior |
|---|---|---|
| Fully researched | Primary federal/state sources reviewed; product matrix approved; counsel/regulatory review complete or explicitly waived | Enable allowed and conditional categories; gate verified categories; block prohibited |
| Partial | Some primary-source review complete, but category gaps remain | Allow only low-risk researched categories; high-risk categories fail closed |
| Unresearched | No reliable primary-source review | Do not enable regulated categories; ordinary low-risk produce only if defensible |
| Blocked | Rules unclear, high-risk, or Gnome lacks operational ability to verify | Save draft only or block public listing |

## Launch Strategy

1. Northeast Ohio first.
2. Ohio product matrix before public seller onboarding.
3. State-by-state expansion only after source review and rule loading.
4. Unknown high-risk categories fail closed.
5. Do not claim nationwide legal readiness.

## Required State Research Packet

For each state, create:

- Product category matrix.
- Cottage food/home bakery rules.
- Egg rules.
- Honey/maple rules.
- Meat/poultry/dairy rules.
- Nursery/plant rules.
- Seed rules.
- Pet food/feed rules.
- Sales-tax/marketplace-facilitator review.
- Local/county items that matter for the launch pocket.
- Professional-review flag.

## Source Rules

Use primary sources first:

- State agriculture department.
- State health department.
- State statutes and administrative code.
- FDA, USDA, USDA FSIS, APHIS, CFR.
- County/local sources only where state rules delegate control.

Do not use blogs, social posts, competitor behavior, or AI memory as final authority.
